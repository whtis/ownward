# Ownward roadmap

Ownward is an early alpha. This is direction, not a compatibility promise.

## Next

- Stabilize the local-first Kernel: session recovery, durable runs, and clear failure states.
- Turn the current Provider contract into an experimental adapter SDK, then add official adapters for more Agent CLIs.
- Keep Vertical and Connector extension contracts small, capability-scoped, and backed by executable contract tests.
- Improve first-run setup, configuration examples, backup guidance, and macOS diagnostics.
- Add public CI, issue triage, release notes, and a compatibility matrix for supported providers and platforms.

## Not planned for the alpha

- A cloud-hosted multi-tenant service or account system.
- An IDE, browser engine, or a replacement for GitHub, Gmail, or collaboration suites.
- A plugin marketplace, automatic third-party downloads, or an OS sandbox for untrusted extensions.
- Autonomous approval of deployments, permanent-memory promotion, or external document publication.

See [README.md](README.md) for the current supported surface and [docs/architecture-v1.md](docs/architecture-v1.md) for the architecture.
