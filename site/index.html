THE GAP BETWEEN TOOLS

烦的不是 AI 不会写，
是工作接不上。

Claude 限流换 Codex，背景要重讲；三个 CLI 改同一个项目，记录散在三处；周报到了，还得翻聊天、对 Git。Ownward 把中间这段接住。

FOUR CONTINUOUS MOVES

把一次开发，
变成可以继续的工作。

01

把记忆归拢到项目

Claude Code、Codex、CodeBuddy 的任务回到同一套记录：目标、过程、diff、commit 和结论。终端里开的会话也能自动收割成 Markdown。

inbox　/　log　/　flights　/　候选记忆
02

限流了，换引擎继续

新引擎接手必要的近期历史、工作目录、附加目录和权限。它先看真实 Git 状态，再继续做事；旧会话链始终可回看。

Claude→Codex→CodeBuddy
03

周报到点自动起草

Routine（默认关闭，需配置飞书）从近期记录、任务结果和项目记忆取材，生成待审草稿。搜集和起草交给 AI，是否写进飞书由你拍板。

等待人工确认 → 写入文档
04

手机连着自己的 Mac

晚上派任务，早上看流式回复、diff、测试和 PR。代码、凭据与 Agent CLI 留在 Mac，手机只负责操作界面。

Mac↔Android / iOS

HONEST BOUNDARIES

Ownward 不是 IDE，也不是 Agent 安全沙箱；Ownward 不把工作记录和凭据集中托管到自有云端；实际模型服务会按你选择的 Provider 政策处理上下文，也不会自动导入 ChatGPT 或 Claude 网页端的全部历史。早期 alpha，安全边界仍然在你这边。
