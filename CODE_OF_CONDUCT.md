# Code of Conduct

We want Ownward to be a respectful, practical space for building durable,
user-controlled AI work tools.

Be constructive, assume good intent, and focus criticism on ideas and implementations.
Harassment, discrimination, threats, doxxing, and publishing another person's private
data are not acceptable.

If you experience or witness a violation, report it privately through the security or
maintainer contact path described in [SECURITY.md](SECURITY.md). Maintainers may remove
content, limit participation, or take other action needed to protect the community.
